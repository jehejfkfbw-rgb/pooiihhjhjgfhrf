# Nova Code — منصة نوفا كود المتكاملة

منصة برمجيات عربية كاملة تخدم **مصر والسعودية فقط**، مبنية على Next.js + PostgreSQL، مع فريق من **7 وكلاء ذكاء اصطناعي يعملون محلياً عبر Ollama** — ولا يُعتمد أي عمل دون موافقة المدير من لوحة التحكم المخفية.

## 1) التشغيل محلياً على جهازك (5 دقائق)

### المتطلبات
- Node.js 20+
- PostgreSQL (أو Docker)
- [Ollama](https://ollama.com/download) — مجاني ويعمل بدون إنترنت بعد التحميل

### الخطوات
```bash
# 1. تثبيت الاعتماديات
npm install

# 2. إعداد قاعدة البيانات — أنشئ ملف .env بهذا السطر:
# DATABASE_URL="postgresql://postgres:postgres@127.0.0.1:5432/app_db"
npx drizzle-kit push          # إنشاء الجداول

# 3. تشغيل المنصة
npm run dev                   # للتطوير
# أو
npm run build && npm start    # للإنتاج
```

### تفعيل الذكاء الاصطناعي المحلي (Ollama)
```bash
# ثبّت Ollama ثم شغّل نموذجاً خفيفاً وسريعاً بالعربية
ollama pull llama3.2:3b
ollama serve
```
> بدون Ollama تعمل المنصة كاملة بوضع "المحاكاة الذكية" (ردود ومقترحات جاهزة عالية الجودة). إذا كان Ollama يعمل على منفذ أو نموذج مختلف، أضف للـ `.env`:
> ```
> OLLAMA_URL="http://localhost:11434"
> OLLAMA_MODEL="llama3.2:3b"
> ```

## 3) فريق العمل الذكي (يعمل محلياً بـ Ollama)

| الفريق | الوكلاء | المهمة |
|---|---|---|
| التطوير والتنفيذ | كريم، سارة، عمر | تحليل طلب العميل وبناء مقترح تنفيذ كامل — **لا يُعتمد إلا بموافقتك من اللوحة** |
| خدمة العملاء | ليلى (مصر)، فهد (السعودية) | رد تلقائي على الزوار، شرح الخدمات والأسعار بالعملتين، توجيه للواتساب والإيميل |
| التسويق الإلكتروني | مروان، دانا | بوستات سوشيال ميديا، سكريبتات تيك توك، وخطط محتوى لمصر والسعودية — **تُعتمد منك قبل النشر** |

### دورة العمل المضبوطة
1. زائر يملأ نموذج "اطلب مشروعك" → يصلك في تبويب **طلبات العملاء**.
2. من تبويب **فريق التطوير** اضغط "تشغيل فريق التطوير" → الوكلاء الثلاثة يجهزون المقترح التقني.
3. راجع المقترح ثم اضغط **اعتماد** أو **رفض** — الاعتماد يعتمد طلب العميل تلقائياً.
4. من تبويب **التسويق** اطلب محتوى بأي موضوع → راجعه واعتمد نشره أو ارفضه.
5. تبويب **المحادثات** يعرض كل ما دار بين الزوار وفريق خدمة العملاء.
6. تبويب **فريق العمل والمهام**: أنشئ حسابات الموظفين، أسند مهمة (مرتبطة بطلب عميل أو حرة)، ثم راجع مخرجاتهم واعتمدها أو أرجعها للتصحيح بملاحظة.
